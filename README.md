# NFSe Solutions

Projeto da disciplina de Dispositivos Móveis (FATEC Praia Grande).

- **`TPNotafiscalAPI/`** — Backend: API REST em Laravel (Etapa 1).
- **`NFSeApp/`** — Frontend: app Expo com CRUD completo de Nota Fiscal,
  usando react-hook-form, zod, @hookform/resolvers, axios e
  @tanstack/react-query, estruturado em `features/` (Etapa 2).

Veja o README de cada pasta para instruções de setup.
